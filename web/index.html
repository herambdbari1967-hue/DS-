Trie (Prefix Tree)

26-way branch tree indexing all prefix completions in sub-microsecond time.

  • Search: $\mathcal{O}(L)$ where $L = \text{word length}$
  • Insert: $\mathcal{O}(L)$
  • Space: $\mathcal{O}(N \times L \times \Sigma)$

Binary Max-Heap

Complete binary tree maintaining frequency priority for Top-$K$ ranking.

  • Push / Pop: $\mathcal{O}(\log M)$
  • Top-K Extract: $\mathcal{O}(K \log M)$
  • Space: $\mathcal{O}(M)$

Levenshtein DP

Bounded Dynamic Programming search with branch pruning for typo correction.

  • Pruned Search: $\mathcal{O}(\text{active branches})$
  • Max Distance: $d \le 2$
  • Recurrence: $\min(\text{insert}, \text{del}, \text{sub})$
